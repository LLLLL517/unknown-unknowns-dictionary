# Unknown Unknowns Dictionary (UUD)

> **一个开源、共建的词典。把各行各业的"黑话"，翻译成所有人都能听懂的大白话。**

## 我们解决什么问题？

在任何一个陌生领域面前，你最大的障碍不是"学不会"，而是**"连搜什么都不知道"**。

听不懂圈子里的黑话，你就被挡在门外。传统词典等你已知词再去查；UUD 反着来——**先摊开一张地图，告诉你这领域有哪些核心概念，再用人话解释给你听。** 它不是从A到Z的词汇表，它是帮你拿到入场券的翻译器。

## 这不是另一个维基百科

-   **不是教科书：** 我们不教你从入门到精通，只负责翻译"黑话"。
-   **不是穷尽一切：** 我们不收录所有词汇，只收录那些**构成认知壁垒的核心词**——听不懂它们，你就没法在这个圈子里混。
-   **按领域分好地图：** 不需要你知道自己要查什么，只需要你知道自己想进哪个领域的门。

## 这里有什么？

-   **学术专业术语区：** 各学科的核心概念，从"社会学想象力"到"反向传播"。
-   **场景黑话区：** 来自职场、互联网圈、饭圈、健身房的"对齐"、"颗粒度"、"力竭"。

## 怎么参与？

UUD 是一个社区共建项目，我们急需各种领域的"翻译官"。无论你是想贡献自己领域的词条，还是想帮我们翻译黑话，都可以看 [贡献指南](CONTRIBUTING.md)。

**"You and Yours, All Need UUD."** —— 你和你关心的人，都需要这本词典。
